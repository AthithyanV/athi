# athi

A simple Python record manager that supports adding, accessing, and inserting records.

## Usage

Run the interactive record manager:

```bash
python records.py
```

Options:
1. **Add record** – append a new record to the collection
2. **Insert record at position** – insert a record at a specific index
3. **Access record by index** – retrieve a record by its index
4. **View all records** – display all stored records
5. **Exit** – quit the program

## Running Tests

```bash
python -m pytest test_records.py -v
```
